
# Portal Educacional de Eletroeletrônica

## Sobre o projeto

Portal educacional desenvolvido para apresentar informações sobre
indutores e eletromagnetismo, com conteúdo técnico, imagens,
aplicações práticas, resumo e quiz interativo.

## Integrantes

- Bruna de Freitas
- Mariana Stein Frandolige

## Tema

1.3 – Indutores e Eletromagnetismo.

## Tecnologias utilizadas

- HTML5: estrutura das páginas.
- CSS3: aparência e organização visual.
- JavaScript: interatividade do quiz.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Estrutura dos arquivos

- `index.html`: página principal.
- `css/style.css`: estilos do portal.
- `js/script.js`: funcionamento do quiz.
- `img/`: imagens utilizadas no projeto.
- `controle_projeto.xlsx`: planilha de acompanhamento.
- `pesquisa_indutores.docx`: pesquisa técnica.

## Recursos

O portal apresenta conceitos de indutância e eletromagnetismo,
exemplos de aplicações práticas, recursos visuais e um quiz.

## Créditos das imagens

As imagens devem ser utilizadas de acordo com as licenças
indicadas em suas páginas originais, com os respectivos créditos.
